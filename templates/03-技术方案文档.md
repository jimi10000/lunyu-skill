## 8. 工程标识（锁死）

**与需求确认单一致，定下即不变。** 跨语言对应物：

| 概念 | 示例 | 适用 |
|---|---|---|
| 工程根目录名 | my-service | 全部 |
| 包名 / Package name | com.xxx.myservice | Java / Kotlin / Android / Python 包 |
| 命名空间 / Namespace | Xxx.Myservice | C# / Rust / TS |
| Application ID | com.xxx.myservice | Android / iOS bundle id |
| GroupId / ArtifactId | com.xxx / myservice | Maven / JVM |

**铁律**：禁止中途改名换包名；改名须走 `templates/09-需求变更记录.md` 并评估连锁影响（依赖引用、CI 配置、发布产物、已发布版本兼容性）。
