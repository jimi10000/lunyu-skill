**锁死规则**：确认即生效，**中途禁止改名换包名、禁止改盘符、禁止换根目录**。任何改名 / 改盘符 / 换根目录 = 范围变更，必须走 `templates/09-需求变更记录.md` 并评估对依赖引用 / CI 配置 / 发布产物的连锁影响；口头变更一律不算数。

> **路径不漂移**：工程根目录绝对路径（含盘符）与「工程根目录名」须一一对应，确认后**全生命周期不变**。流水线重跑、换机器执行、定时任务触发，**都落到同一个绝对路径**——绝不允许多次执行落在 C 盘又跑到 D 盘、或换目录重开一份。lunyu 不替项目"造"目录，根目录由你在确认单里一次性定死。

## 协作约定（含多 AI 并行）

- **唯一事实源**：项目源码以 git 仓库为唯一事实源，所有协作者（含不同 AI agent）必须从同一仓库同一分支拉取，**禁止各自持游离副本、禁止各存各的目录**
- **开工前同步基线**：任何 AI / 人必须先 `git fetch && git checkout <基线分支> && git pull --rebase` 拿到最新 HEAD，再基于最新 commit 开工；**禁止"找到一份旧源码就开干"**
- **责任区隔离**：多 AI / 多人并行时按模块 / 目录 / 文件划责任区，各自走独立 `feature/<模块>-<负责人>` 分支，**禁止两个 agent 同时改同一文件**；合入统一走 PR + CR（Step 7）
- **落盘唯一**：所有协作者（含 AI）都把项目落到「工程根目录绝对路径（锁死）」那一个路径，不得各放各的
