# lunyu 上架 WorkBuddy 技能市场 —— 操作指引

> 已帮你查好完整上架流程，zip 包也已备好。以下照着填就行，全程不需要写代码。

## 一、前置条件

- 注册 WorkBuddy 开放平台：https://open.workbuddy.cn
- 完成**开发者认证**（个人实名即可，需姓名、手机号、身份证/证件）
- 准备 zip 包：`lunyu-v1.1.3.zip`（已在此目录，45 个文件，含 104 个单元测试）
  - 若以后更新了版本，用更新后的 zip

## 二、上架步骤

### 第 1 步：注册 + 开发者认证

1. 打开 https://open.workbuddy.cn ，注册登录
2. 按提示做开发者认证（个人开发者即可）
3. 认证通过后，左侧出现「技能」发布管理入口

### 第 2 步：上传技能 zip

进入「技能发布管理 / 新建技能」：
- 拖拽上传 `lunyu-v1.1.3.zip`
- 若报格式错误，把报错原文丢回来给我改

### 第 3 步：填写资料（照抄下面）

| 字段 | 填写内容 |
|---|---|
| **技能名称** | 论语 · 企业级研发流水线 |
| **分类** | 开发工具 / 工程效率 |
| **一句话简介** | 让 AI 按正规企业研发流程写代码：需求→方案→编码→自测→CR→版本→复盘，内置日志系统、密钥扫描、缺陷台账、日报周报、打包测试发包 |
| **功能介绍** | 见下方「功能简介」 |
| **适用行业** | 软件研发 / 互联网 / 交付型项目 |
| **使用说明** | 安装后新会话说「写代码」或「提 bug」自动触发；也可直接运行 scripts/ 下脚本 |
| **风险提示** | 脚本会读写项目目录（.lunyu/ 数据文件），凭据请用环境变量注入，勿硬编码 |
| **标签** | 研发流程、代码评审、日志系统、缺陷管理、版本管理、日报周报 |

### 第 4 步：提交审核

- 官方 7 个工作日内，实测一般 24 小时内通过
- 审核通过后即上架，可生成链接/二维码分享

## 三、功能简介（复制用）

论语把正规企业研发流程压缩成 12 步流水线，每一步都有可执行脚本和交付物模板：

1. **三通道机制**：按改动规模自动分快速/标准/完整通道，不把 30 行脚本走成 12 步
2. **分类日志系统**：一键生成 Python/TS 日志模块（按问题域分类 + trace_id + 分级 + 结构化字段）
3. **提交前密钥扫描**：拦硬编码密钥、调试残留、大文件、.gitignore 缺项
4. **缺陷工单台账**：P0-P3 分级、状态流转、CI 门禁
5. **版本归档 + 回滚**：CHANGELOG、tag、回滚预案一条命令生成
6. **日报/周报/项目总结**：自动汇总台账数据，好记性不如烂笔头
7. **自动化打包测试发包**：Gradle 打包 + 模拟器冒烟测试 + 双端发布 + SMTP 发信
8. **一键自更新**：已安装用户一条命令从 GitHub 拉最新版

## 四、后续：开通付费（可选）

1. 先上架一个**免费**技能（即本技能）并通过审核
2. 左侧出现「收入变现」入口，填资料开通收款（微信签约）
3. 再把技能切为付费（注意：付费方式选定后不可改）

> 建议先免费发布积累用户，再考虑定价。

## 五、注意事项

- 付费模式一旦选定不能改（买断 / 订阅）
- 技能包结构必须符合规范：SKILL.md（frontmatter + 正文）+ references/ + scripts/ + templates/
- 本包已含 `templates/` 目录（交付物模板），符合规范
- 脚本零硬编码凭据，可放心过审
