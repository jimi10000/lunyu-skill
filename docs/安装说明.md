# 论语 · 企业级研发流水线 —— 本地安装包

## 这是什么

以《论语》为工程价值观内核的企业级研发流水线 Agent Skill。
需求评审 → 方案设计 → 开源预研 → 编码 → 自测 → CR → 版本归档 → 风险评估 → 复盘 → 日报周报。
内置分类日志系统、密钥扫描、缺陷工单台账、发布回滚、项目总结/日报/周报自动生成、自动化打包测试发包。

## 安装方法（WorkBuddy）

1. 解压本 zip，得到 `lunyu/` 文件夹
2. 把这个文件夹复制到你的 WorkBuddy 技能目录：
   - Windows: `C:\Users\<你的用户名>\.workbuddy\skills\lunyu`
   - macOS/Linux: `~/.workbuddy/skills/lunyu`
3. 重启 WorkBuddy
4. 新开会话，说「写代码」或「提 bug」即可自动触发

验证是否安装成功：新会话里输入「用论语流程帮我写个需求确认单」，看是否回复。

## 快速上手

```bash
# 1. 判通道（别把 30 行脚本走成 12 步）
python scripts/flow.py

# 2. 写代码时接分类日志
python scripts/logkit.py init --lang python --dest ./src/logkit

# 3. 提交前扫密钥
python scripts/preflight.py

# 4. 登记缺陷 / 打版本
python scripts/bug_ledger.py add --title "空数组越界" --priority P1
python scripts/release_note.py tag --version 1.0.0 --summary "首个版本"

# 5. 写日报 / 周报 / 项目总结
python scripts/report.py daily --project "我的项目" --body "今天完成XX"
python scripts/report.py weekly --project "我的项目" --body "本周完成XX"
python scripts/report.py summary --project "我的项目 v1.0" --body "核心成果"

# 6. 注册每天 18:00 自动生成日报（Windows / Linux / macOS）
python scripts/scheduler.py install --time 18:00 --project "C:/我的项目" --author "你"

# 7. 跑单元测试（修改脚本后防止回归）
python tests/run_tests.py

# 8. 一键自更新（已安装用户）
bash scripts/self_update.sh
```

## 脚本一览

| 脚本 | 作用 | 退出码 |
|---|---|---|
| `flow.py` | 判通道（快速/标准/完整） | 0=无改动 |
| `logkit.py` | 生成分类日志系统（Python/TS） | 0=成功 |
| `preflight.py` | 扫密钥/大文件/调试残留/.gitignore | 0=通过 / 1=阻断 / 2=警告 |
| `bug_ledger.py` | 缺陷台账 P0-P3 + 门禁校验 | stats 有未关闭 P0/P1 返回 1 |
| `release_note.py` | 版本存档 + CHANGELOG + tag/回滚 | 有未关闭 P0/P1 返回 2 |
| `report.py` | 项目总结/日报/周报自动生成 | 0=成功 |
| `scheduler.py` | 注册/卸载/查看每日自动日报定时任务 | 0=成功 / 1=失败 |
| `daily_report.sh` | 定时任务入口：生成今日日报 | 0=成功 |
| `build_apk.sh` | Gradle 打包 APK + md5 | 0=成功 |
| `vm_test.sh` | README 冒烟测试（安装/启动/截图/抓崩溃） | 0=通过 / 1=失败 |
| `send_mail.py` | 带附件邮件发送（SMTP） | 0=成功 / 1=失败 |
| `release.py` | 双端发布 GitHub+Gitee | 0=成功 / 1=失败 |
| `github-publish.sh` | 一键建 GitHub 仓库并推送 | 0=成功 |
| `self_update.sh` | 一键自更新技能包 | 0=已最新/成功 / 1=失败 |

> **安全说明**：所有脚本的凭据（GitHub PAT、Gitee token、SMTP 授权码）一律通过环境变量传入，脚本内零硬编码。请用环境变量 `GITHUB_USER` / `GITHUB_TOKEN` / `GITHUB_REPO` / `GITEE_USER` / `GITEE_TOKEN` / `GITEE_REPO` / `SMTP_SENDER` / `SMTP_AUTH` / `SMTP_RECEIVER` 配置账号，不要把真实账号写进脚本。

## 环境要求

- Python 3.8+（脚本零外部依赖）
- WorkBuddy 或其他支持 Agent Skill 的平台
- `build_apk.sh` / `vm_test.sh` 需要 Android SDK；`send_mail.py` / `release.py` / `github-publish.sh` 需要网络
